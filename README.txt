Binary classification of pigmented SKIN lesions, based on the HAM10000 dataset (https://www.kaggle.com/datasets/kmader/skin-cancer-mnist-ham10000).
Classification distinguishes between malignant and non-malignant lesions with a macro average f1 score of 0.81. 
Confusion matrix, AUC-ROC curve and some false negatives are included as an analysis.

Demo at https://huggingface.co/spaces/anevarela/ham10000-skin-classifier
